# Personal scripts

## gi
- **Single command for `git add .`, `git commit`, and `git push`**
- -u flag:
    - runs `git push -u origin <branch>` rather than `git push`
    - <branch> is `main` by default (`gi -u 'msg'`) or can be specified by passing as a variable e.g. `gi -u=branch 'msg'`

## apps-not-brew
- Lists third party applications not installed by homebrew

## hc2p
- convert .HEIC images to .png
